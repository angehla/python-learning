# python-learning

My space for learning Python through small beginner projects.

## Projects

### 1. Number Guessing Game (`number_guessing_game.py`)
The computer picks a random number between 1 and 100, and you try to guess it. After each guess it tells you whether you're too high or too low, and it tracks your best score across rounds.

**Concepts practiced:**
- Variables and user input
- `while` loops and `if / elif / else`
- Functions with default arguments
- Error handling with `try / except`
- The `random` module

**Run it:**
```bash
python number_guessing_game.py
```
